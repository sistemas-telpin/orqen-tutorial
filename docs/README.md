# Documentación del proyecto

Esta carpeta explica el repositorio de referencia para el tutorial interactivo de ORQEN Desktop, para que puedas entenderlo sin leer el código.

- [arquitectura.md](arquitectura.md): estructura del repo y el rol de `scenario.mjs`, `generate.mjs`, `project.json` y `orqen/`.
- [pruebas.md](pruebas.md): cómo ejecutar los tests con `node --test` y qué cubre cada test en `scripts/`.
- [interno.md](interno.md): nota interna generada por un desarrollo interno de orqen (sin pedido ni issue).
- [prueba-orqen.md](prueba-orqen.md): documento de prueba generado por el flujo de orqen.

Para el contexto general del proyecto, vuelve al [README principal](../README.md).
