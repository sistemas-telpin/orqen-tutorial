# Flujo completo de orqen

1. Listar el trabajo por rol (`/orqen:list requests`).
2. Soporte responde o escala (`/orqen:support`).
3. Análisis con el analista (`/orqen:analyze`).
4. Desarrollo lista sus issues (`/orqen:list issues`).
5. Implementación y TESTING (`/orqen:implement`).
6. Abrir el PR (`/orqen:pr`).
7. Revisión de QA en el carril full (`/orqen:review`).
8. El senior lista los PRs (`/orqen:list prs`).
9. El senior aprueba o pide cambios (`/orqen:approve`).
